Display Mode

Separate: each county shows an inbound and an outbound circle side by side (Inbound left, Outbound right). Combined: one circle for both directions. When both directions are ticked, each direction's circles are sized on their own scale, so compare sizes within a direction, not between Inbound and Outbound.

Shaded counties show one value per county: the combined total of the directions ticked.

Movement between counties

Lines join the centers of two Washington counties, with the arrowhead at the destination. Pairs are ranked by what "Show charts by:" counts (animals unless changed): ranks 1 to 5 thickest and darkest, then 6 to 10, 11 to 25 and 26 to 50, each thinner and lighter. A ring marks animals moved within one county. Lines are not travel routes. A movement within Washington is both a departure and an arrival, so Direction does not split this view.

Map Style
WA State Style
Show counties as

Circles: one circle per county, sized by its animals. Shaded counties: each county filled by its animals, light to dark, in classes (a choropleth). On Total animals, bigger counties can look busier because they are bigger; Animals per square mile corrects for county size. Counties with no movements are hatched.

Total animals: the county's animals for the filters and period, as the circles count them. Animals per square mile: that total divided by the county's land area (2020 Census), so large counties do not look busier only because of their size.

How the counties are grouped into colors. Natural breaks: classes split where the values jump. Quantile: each class holds about the same number of counties. Set how many with Number of bins (at most 5 while shaded).

Logarithmic, Square root and Linear size circles; shaded counties need classes.

How a county's animal count sets its circle's area. Logarithmic: shrinks big differences, so small counties stay visible; best when a few counties are far larger than the rest. Square root: a gentler squeeze. Linear: area in direct proportion; the largest get very large. Quantile: a few fixed sizes, each holding about the same number of counties. Natural breaks: a few fixed sizes, split where the counts jump. Set how many with Number of bins. This page opens on Logarithmic.

The number of circle sizes for Quantile or Natural breaks. More sizes show finer differences but make a busier legend; 5 is a good default.

Shaded maps show at most 5 classes, so neighboring colors stay apart.

Colors for the circles. On a light map, High Contrast makes the circles stand out most.

Shaded counties use the ColorBrewer ramp of the direction shown.

National Flow Style
Show states as

Lines: one line from Washington to each state, colored by species, its width by the animals moved. Shaded states: each state filled by its animals moved with Washington, light to dark, in classes (a choropleth); species are added together; Washington is the white hub. States with no movements stay plain gray.

How the states are grouped into colors. Natural breaks: classes split where the values jump. Quantile: each class holds about the same number of states. Set how many with Number of bins (at most 5 while shaded).

Logarithmic, Square root and Linear set line widths; shaded states need classes.

How the animals moved sets its line's width. Logarithmic: shrinks big differences, so small lines stay visible; best when a few lines are far larger than the rest. Square root: a gentler squeeze. Linear: width in direct proportion; the largest get very wide. Quantile: a few fixed widths, each holding about the same number of lines. Natural breaks: a few fixed widths, split where the counts jump. Set how many with Number of bins. This page opens on Natural breaks.

The number of line widths for Quantile or Natural breaks. More widths show finer differences but make a busier legend; 5 is a good default.

Shaded maps show at most 5 classes, so neighboring colors stay apart.

Multiplies every line's width after the scaling above; 1.0 changes nothing. Raise it for thicker lines in screenshots and slides; lower it when many lines overlap.

Population context

The current legal limits of every incorporated city and town in Washington, from the WA Department of Revenue (updated quarterly), with each city's 2020 Census population. With Population centers also on, cities are outlined from these limits only.

Every 2020 Census place: the incorporated cities and towns (solid outline, their 2020 limits) and the census-designated places, the named unincorporated communities (dashed). With City limits also on, only the census-designated places are drawn, each cut to the part outside current city limits.

People per square mile of land in each 2020 Census tract, in six fixed classes from under 10 to 5,000 and over, drawn under the data. Context only: no count or circle changes.

Names: places of 10,000 people or more on WA State; every city and place in the picked counties on County Focus.

Export & Preview

Each export is one ZIP file, handed to your browser to save (usually your Downloads folder).

Export Details

A name for the ZIP file and the folder inside it. Leave blank for the automatic name, YYYY-MM-DD_MapType_Area_Species_Direction. If a file of that name exists, your browser adds a number.

Do not type a person's name or a case number here: it is saved in the PNG and export_params.json.

Your own header text for the branded PNG, up to 80 characters. Leave blank for the automatic title from the filters (for example TOTAL ANIMAL IMPORTS – CATTLE).

PNG Rendering

The background of Preview Map and the branded PNG. Default is the report-style WSDA background and needs no network. Satellite, Shaded Relief and Hillshade (WA State and County Focus) come from Esri's servers; if one cannot be loaded, Default is used and a notice says so. Streets (vector), County Focus only, draws roads, water and place names from bundled Census data, with no network. The live map's basemap does not change the PNG.

Alternate PNG backgrounds are available for WA State and County Focus only.

The detail of the Satellite, Shaded Relief and Hillshade backgrounds. Standard: fast; fine for screens and reports. High: sharper (tile zoom +2) but slower; for print.

Standard: the branded map at 200 dpi and the charts at 150 dpi, as CVI writes them. High: 300 dpi for both (the branded map 3300 x 2550 pixels, a chart 2400 x 1500), sharper in print, larger files.

Tables

The rows the map draws, one per CVI record, after the filters. Written as filtered_rows.csv.

Visualizations

The view's charts as Map + charts or Charts shows them, counted by "Show charts by:". The over-time chart and the heatmaps (animals by species and period; on WA State and National Flow also the top 10 places by period) only when the rows span two or more periods. Written to charts/.

The branded PNG, as Preview Map shows it, at full size for slides and reports.

An animated GIF of the map, one frame per quarter or year (set under "GIF frame interval"). Circle sizes, line widths and the legend use one scale for every frame (on a shaded map, one set of classes), so frames can be compared. In Compare, the GIF shows the left map. It is drawn on the Default background (or Streets on County Focus). A GIF loops without end: on a web page, put a still picture (the branded PNG) beside it.

What each GIF frame covers. Quarter gives a smoother animation; Year a smaller file.

Name markers in PNG

    Locations to query
    Add a site

    Enter a name and coordinates, then click Add site. Added sites appear in the Sites to query table. Buffer is optional — leave it blank to use the default buffer / preset above.

    Or click Pick on map, then click the match map to fill in the latitude and longitude.

    A CSV with the columns address, lat, long, such as CVI's geocode_cache.csv. Find coordinates looks the address up in it. The file is read in this browser and never sent anywhere; no address is looked up online.

    Do not type a person's name or a case number here: it is saved in the PNG and export_params.json.

    Paste / upload bulk locations

    Format: name, lat, long. Add one number for a single buffer (km), or two or more for concentric bands (e.g. ...,-120.2, 1, 3, 5 = 1/3/5 km rings).

    Required columns: name, lat, long. Optional: buffer_km (uses default above when blank).

    Zones from a file (polygons)

    GeoJSON, KML or a zipped shapefile, in longitude and latitude (WGS 84 or NAD 83). Each polygon becomes a site: a CVI or facility matches when it lies inside the polygon. The file is read in this browser and never sent anywhere.
