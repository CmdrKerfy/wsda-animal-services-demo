Changing the kinds of animals

Emergency Response dashboard · for whoever keeps the type file · also as CHANGING_THE_KINDS_OF_ANIMALS.txt beside this page · Open the Emergency dashboard

The Emergency page sorts each positive into a kind of animal (for HPAI: Birds, Cattle, Other animals) by the words in its Species column. The kinds and their words are kept in one file, hpai.js, in the dashboards’ folder under site/emergency/types/. Each kind gets its own mark on the map, its own tick under “Animals”, its own row in the legend and the map picture’s key, its own color in the Overview, and its own totals. Changing that one file is the whole change; no other file needs it.

Before you start

  • First keep a copy: in the folder, copy hpai.js and paste it there (it is named “hpai copy.js” or “hpai - Copy.js”; the page ignores it). If something goes wrong, you can put it back.
  • Open hpai.js in a plain-text editor: Notepad on Windows (right-click the file, Open with, Notepad), TextEdit on a Mac (right-click the file, Open With, TextEdit). Not Word: it would change the file.
  • To find a line in it: Edit, Find (Ctrl+F on Windows, Command-F on a Mac), then paste the line.
  • After each change: save hpai.js (File, Save), then reload the Emergency page in the browser (F5 on Windows, Command-R on a Mac). The page reads the file each time it opens.
Copy, don’t type. Use the Copy buttons below. TextEdit turns typed quotes into curly ones (‘ ’), which the page cannot read. (Or first turn it off: Edit, Substitutions, Smart Quotes.)
On the R drive, a changed file changes the page for everyone, and the next version’s folder replaces it. Send your change to the platform’s maintainer so it goes into the next version too.

Adding a word

Use this when the line under the value boxes names a species the page does not know, for example “1 positive with a species not listed: Opossum”. That positive was counted under the last kind, Other animals.

1In hpai.js, find the end of Other animals’ words:

Find'deer', 'elk', 'wolf', 'dolphin', 'porpoise'] }

2Add the new word in quotes, after a comma:

Change it to'deer', 'elk', 'wolf', 'dolphin', 'porpoise', 'opossum'] }

3Save, and reload the page. Opossum is no longer in the “not listed” line.

Write the word in small letters: it matches “Opossum”, “OPOSSUM” and “Virginia opossum” alike. Other animals counts each species by its own name (“12 goats, 1 opossum”); Birds and Cattle count by the kind’s name (“1.2M birds”).

Worked example: show mink apart from other animals

Mink are counted under Other animals, with the triangle. Two edits give them their own kind.

1Add the Mink kind

Find the cattle kind, the line that starts{ key: 'cattle', label: 'Cattle', words: [
Paste right under it, before Other animals{ key: 'mink', label: 'Mink', words: ['mink'] },
  • key: a short code name the page uses behind the scenes (small letters, digits and dashes only; each kind’s different)
  • label: the name people see on the tick, the legend and the map picture’s key
  • words: the species words that make a positive this kind, each in quotes, with commas between
  • The counts use the label in small letters (“7 mink”). To have them say something else, such as “7 animals”, add word: 'animals', after label: 'Mink', in the line.

2Take mink out of Other animals

In Other animals’ words, delete (with its comma and space)'mink',

Delete the quotes, the word, the comma and the space after it. A word may be in one kind only; if it is left in both, the page shows a red notice (see “What a slip looks like”).

3Check the page

Save, reload the page, and load your positives file. “Animals” now has four ticks: Birds, Cattle, Mink, Other animals.

The rules

Order matters
The marks go by the kinds’ order: circle, square, triangle, diamond, pentagon, hexagon. So do the colors, the ticks and the legend. A kind put in the middle moves every kind after it to the next mark and color.
The catch-all goes last
The last kind also takes every species no kind names, and the line under the value boxes names them. Keep the broadest kind (Other animals) last. A positive with no species at all is the first kind (Birds).
Six kinds are told apart
A seventh kind or later shares the hexagon and the sixth color; its legend row says “same mark as” the sixth. It keeps its own tick and counts.
A word matches at the start of a word, in any case
“cow”matches “Dairy cow” and “Cows” “cat”does not match “Bobcat” “mink”also matches “Minke whale”
Where two words start at the same place, the longer wins: “pigeon” (a bird word) keeps “Racing pigeon” from being a pig. So to keep Minke whales out of Mink, add 'minke whale' to Other animals.
A species naming two kinds is both
“Cattle, Chicken” shows while either kind is ticked, has both marks side by side, its animals are counted in neither kind, and a line under the value boxes names it.
What the page refuses
The same word in two kinds, and a kind with no words (only the last kind may have none). Either one gives the red notice.

The work-PC table check keeps its own copy

The HPAI table check (the small tool that checks the agency’s HPAI table on the work PC, in the tools/work-pc/ folder) keeps its own copy of the same words, so it can run without the dashboard. Open its file, check_hpai_table.R, in Notepad or TextEdit the same way and make the same two changes. What a slip looks like

If the page cannot use hpai.js, it leaves HPAI out and shows a red notice at the top of the sidebar. The emergency type list (under “Positives and zones”) then has no HPAI, and the page would read your HPAI file as the wrong emergency, so fix the file before going on.

Mink left in Other animals as well

The emergency type file "types/hpai.js" was not used. Emergency type "hpai": "kinds[3].words" should be words no earlier kind has ("mink" is in kinds[2], "Mink", too).

How to read it: “kinds[3]” means the 4th kind in the list, because the page counts from 0: kinds[0] is Birds, kinds[1] Cattle, kinds[2] Mink, kinds[3] Other animals. So the word “mink” is in both Mink and Other animals.

A slip in the writing itself (curly quotes, a missing comma, quote or bracket)

The emergency type file "types/hpai.js" could not be read: a typing slip in it, such as quotes made curly or a missing comma or bracket, or the file is missing.

To fix: undo the last change (Edit, Undo), or compare your lines with the ones above, then save and reload again. Still stuck: put back your copy (delete hpai.js, then rename the copy to hpai.js), and ask the platform’s maintainer.

For a maintainer: the other parts of a type file are explained at the top of hpai.js, and “Adding an emergency type” in docs/DEVELOPER_GUIDE.md says how to add a type.
